# JooPeter Email to Product Buyers for WooCommerce

A WooCommerce utility plugin that allows store admins and authorized roles to send customized emails to customers who bought specific products.

## Features
- Filter buyers by order status (Processing, On Hold, Completed).
- Live customer count preview.
- Batch sending via AJAX to avoid server timeouts.
- 10-second cancelable sending queue.
- Email logs dashboard with search, status filters, and one-click retry for failed attempts.
- Configurable log retention settings.
- Role-based permissions to control access to the sending metabox.

## Requirements
- WordPress 6.0+
- PHP 7.4+
- WooCommerce 6.0+
